# 🏨 Hotel Room Booking System

A web-based Hotel Room Booking System developed as a Teacher Assessment project. The application allows hotel staff to manage rooms, search room availability, create guest bookings, cancel bookings, and prevent double-booking of rooms.

## 📌 Project Overview

The Hotel Room Booking System provides a simple and efficient way to manage hotel rooms and reservations through a web interface.

The system uses a database to store room and booking information and dynamically updates room availability when bookings are created or cancelled.

## ✨ Features

- 🏨 Add and manage hotel rooms
- 🔍 Search rooms by room number, room type, and date
- 📅 Check room availability
- 👤 Create guest bookings
- ❌ Cancel existing bookings
- 🔄 Dynamic room availability updates
- 🛡️ Double-booking prevention
- 💾 SQLite database storage
- 📱 Clean and responsive web interface
- ⚡ Fast local web application

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js
- **Framework:** Express.js
- **Database:** SQLite
- **Package Manager:** npm
